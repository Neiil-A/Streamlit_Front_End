# Stop Looking at my Computer News

A personal reading page: the day's news from free public sources (NPR, The Guardian, Al Jazeera, DW, PBS
NewsHour, ProPublica, Ars Technica, Quanta, Aeon, The Conversation, Smithsonian, Literary Hub, ESPN and
others), laid out like a newspaper, with sports from ESPN's public scoreboards. Headlines and summaries
belong to their publishers, name their outlet and link to the originals. Not a product or service.

Streamlit Community Cloud: main file `streamlit_app.py` (or `press/app.py`). Works with no settings; the password is
built in as a one-way hash. Optional Secrets: `GUARDIAN_API_KEY`, `NYT_API_KEY` (more sources), `APP_PASSWORD` (a new password).

This repository is generated from the main project; edit there, not here.
